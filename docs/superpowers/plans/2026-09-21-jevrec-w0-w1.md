# JevRec W0–W1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a JevRec model whose correctness has been verified and that can be trained, obtain the first set of ranking numbers on KuaiRand, and reach the G2 Go/No-Go gate.

**Architecture:** Qwen3-Base with the LM head removed, input layout `[user context][cand_1]...[cand_N]`, using a **block-diagonal attention mask** so each candidate can only see the context and itself, paired with **per-segment reset position_ids** to guarantee the output is strictly invariant to candidate permutation. A single forward pass produces N scores.

**Tech Stack:** PyTorch 2.8.0+cu128 · transformers · Qwen3-0.6B/1.7B-Base · SDPA 4D additive mask (correctness path) → FlexAttention (performance-optimization path) · pytest

**Spec:** [`docs/superpowers/specs/2026-09-21-jevrec-design.md`](../specs/2026-09-21-jevrec-design.md)

## Global Constraints

The following values are copied verbatim from the spec — **every task's requirements implicitly include this section**:

- **Repo language convention**: this repository is intended for open-source release, so all code comments, docstrings, documentation, and commit messages are written in English.
- **Only two sets of model weights are used**: `Qwen3-0.6B-Base` (primary), `Qwen3-1.7B-Base` (scaling comparison). **No 4B.**
- **Use Base, not Instruct**, full-parameter fine-tuning.
- Context length **L = 20** historical items.
- Candidate count: **training N = 20 (1 positive, 19 negatives)**, **evaluation N = 100**.
- Per-item text length: **KuaiRand L_cand = 24 tokens**, **Amazon L_cand = 48 tokens**.
- Candidate segments use **left padding** (guarantees the scoring position is fixed at the end of the segment).
- **position_ids reset per segment**: context uses `0..L_ctx-1`, and every candidate segment restarts from `L_ctx`.
- Binary fields (click / like / follow) use a **scalar sigmoid head**; watch-ratio uses a **K-bin distributional head, default K = 64**.
- The `forward` signal is too sparse, **not included in the main experiments**.
- Training loss: `L = L_rank(listwise) + λ · L_cal(pointwise BCE)`, **a single shared score**, no dual head.
- Base-rate correction (Elkan) **is applied at inference/evaluation time**; training uses raw BCE.
- **The debiasing ladder's L1 is not optional.**
- Remote execution: `ssh autodl`. Code lives at `/root/project/jevrec` (synced from local; **local is the single source of truth, never commit on the remote**).
- **All datasets, model weights, and checkpoints always go to `/root/autodl-tmp/`**, never to the system disk.
- Currently only **1 card** is rented; the dual-card plan in spec §8.1 is deferred and to be reassessed after G1. W0–W1 only ever needs 1 card anyway.

**Hard disk constraints (the data disk is only 60G — these are rules, not suggestions):**

1. **Keep only one checkpoint at a time.** Evaluate immediately after training ends → persist prediction files and metrics (a few MB) → **delete the weights**. Calibration analysis consumes predictions, not weights. Only the 2–3 runs that make it into the paper get their weights archived.
2. **Store only bf16 weights, never optimizer state** (except for the resume point of the currently active run).
3. **Delete Amazon raw files immediately after processing** — they can be re-downloaded from HuggingFace, so this is not unrecoverable data.
4. **Preprocessing outputs store token-id arrays (npz), not text.**
5. **Every disk-writing script must pass the disk guard before starting** (see Task 1 Step 5): if remaining space is below the threshold, error out immediately — **never allowed to run halfway and blow the disk** — checkpoint corruption from a full disk is usually only discovered the next time it's loaded, by which point dozens of GPU-hours have already been wasted.

- Fix the random seed, default `seed = 42`.

```python
# scripts/probe_env.py
"""W0 blocking item: confirm SWA, measure real tokens/sec, tally the volume of KuaiRand random-exposure samples."""
import os, time, argparse, torch
from transformers import AutoConfig, AutoModelForCausalLM

os.environ.setdefault("HF_HOME", "/root/autodl-tmp/hf")


def check_swa(model_id: str) -> bool:
    """Returns True if sliding-window layers are present (this would break the block-diagonal mask's semantics)."""
    cfg = AutoConfig.from_pretrained(model_id)
    use_swa = bool(getattr(cfg, "use_sliding_window", False))
    window = getattr(cfg, "sliding_window", None)
    layer_types = getattr(cfg, "layer_types", None)
    print(f"  use_sliding_window={use_swa} sliding_window={window} layer_types={layer_types}")
    if layer_types is not None:
        return any("sliding" in str(t) for t in layer_types)
    return use_swa and window is not None


def measure_tokens_per_sec(model_id: str, seq_len: int, batch: int, steps: int = 12) -> float:
    """Real forward+backward throughput. The first 4 steps are discarded as warmup."""
    model = AutoModelForCausalLM.from_pretrained(
        model_id, torch_dtype=torch.bfloat16, attn_implementation="sdpa"
    ).cuda()
    model.gradient_checkpointing_disable()
    model.train()
    opt = torch.optim.AdamW(model.parameters(), lr=1e-5)
    ids = torch.randint(0, 1000, (batch, seq_len), device="cuda")
    elapsed = 0.0
    for i in range(steps):
        torch.cuda.synchronize(); t0 = time.perf_counter()
        out = model(input_ids=ids, labels=ids)
        out.loss.backward(); opt.step(); opt.zero_grad(set_to_none=True)
        torch.cuda.synchronize()
        if i >= 4:
            elapsed += time.perf_counter() - t0
    return (steps - 4) * batch * seq_len / elapsed


def count_kuairand_random(data_dir: str) -> int:
    import pandas as pd, glob
    total = 0
    for f in glob.glob(os.path.join(data_dir, "*.csv")):
        for chunk in pd.read_csv(f, usecols=lambda c: c == "is_random", chunksize=500_000):
            if "is_random" in chunk:
                total += int(chunk["is_random"].sum())
    return total


if __name__ == "__main__":
    ap = argparse.ArgumentParser()
    ap.add_argument("--model", default="Qwen/Qwen3-0.6B-Base")
    ap.add_argument("--seq-len", type=int, default=1000)
    ap.add_argument("--batch", type=int, default=8)
    ap.add_argument("--kuairand-dir", default="/root/autodl-tmp/data/KuaiRand-Pure/data")
    a = ap.parse_args()

    print(f"=== SWA check: {a.model} ===")
    swa = check_swa(a.model)
    print(f"SWA_PRESENT: {swa}")

    print(f"=== Measured throughput (seq_len={a.seq_len}, batch={a.batch}) ===")
    tps = measure_tokens_per_sec(a.model, a.seq_len, a.batch)
    print(f"TOKENS_PER_SEC: {tps:.0f}")
    print(f"  i.e. one {a.seq_len}-token training sample ≈ {a.seq_len / tps * 1000:.1f} ms")

    if os.path.isdir(a.kuairand_dir):
        n = count_kuairand_random(a.kuairand_dir)
        print(f"KUAIRAND_RANDOM_ROWS: {n}")
    else:
        print("KUAIRAND_RANDOM_ROWS: SKIPPED (data not downloaded)")
```

```python
"""Disk guard. The data disk is only 60G; filling it up silently corrupts checkpoints."""
import shutil


class DiskSpaceError(RuntimeError):
    pass


def free_gb(path: str = "/root/autodl-tmp") -> float:
    return shutil.disk_usage(path).free / 2**30


def require_free_gb(need: float, path: str = "/root/autodl-tmp") -> None:
    """Raise immediately when free space is insufficient, instead of letting a run
    fail halfway through by filling up the disk."""
    have = free_gb(path)
    if have < need:
        raise DiskSpaceError(
            f"{path} has {have:.1f}G free, below the required {need:.1f}G. "
            f"Please clean up first: old checkpoints (keep only 1), raw Amazon files, HF cache."
        )
```

```python
# src/jevrec/data/schema.py
"""The unified sample format shared by both datasets (spec §3.1)."""
from dataclasses import dataclass, field
import numpy as np


@dataclass
class RankingSample:
    """A single ranking sample: one shared context + N candidates + multi-target labels for each candidate."""
    user_id: str
    context_texts: list[str]          # text of the L historical items
    candidate_texts: list[str]        # text of the N candidate items
    labels: dict[str, np.ndarray]     # target name -> array of shape (N,)
    is_random_exposure: bool = False  # KuaiRand's unbiased random-exposure flag
    meta: dict = field(default_factory=dict)

    @property
    def n_candidates(self) -> int:
        return len(self.candidate_texts)


def validate_sample(s: RankingSample) -> None:
    """Structural validation. Every sample must pass through this in the data pipeline — failing early beats discovering the problem halfway through training."""
    if not s.context_texts:
        raise ValueError(f"user={s.user_id}: context must not be empty")
    if not s.candidate_texts:
        raise ValueError(f"user={s.user_id}: candidates must not be empty")
    if not s.labels:
        raise ValueError(f"user={s.user_id}: labels must not be empty")
    n = s.n_candidates
    for name, arr in s.labels.items():
        if len(arr) != n:
            raise ValueError(
                f"user={s.user_id}: label {name!r} length {len(arr)} does not match candidate count {n}"
            )
```

```python
# src/jevrec/data/text.py
"""item → text template.

KuaiRand's item side has almost no text (spec §3.3 already declares this a known
limitation of the dataset), so structured features have to be stitched into a
short sentence; Amazon, by contrast, has real title/category/description text.
"""


def _get(row: dict, key: str, default=None):
    v = row.get(key, default)
    if v is None or (isinstance(v, float) and v != v):  # NaN
        return default
    return v


def kuairand_item_text(row: dict) -> str:
    parts = []
    dur = _get(row, "duration_ms")
    if dur:
        parts.append(f"{int(dur) // 1000}秒")
    vt = _get(row, "video_type")
    if vt:
        parts.append(str(vt).lower())
    parts.append("短视频")
    tag = _get(row, "tag")
    if tag:
        parts.append(f"标签:{tag}")
    return "一个" + "".join(parts[:3]) + ("，" + parts[3] if len(parts) > 3 else "")


def amazon_item_text(row: dict, desc_chars: int = 100) -> str:
    fields = []
    for key in ("title", "main_category", "brand"):
        v = _get(row, key)
        if v:
            fields.append(str(v))
    price = _get(row, "price")
    if price:
        fields.append(f"${price}")
    desc = _get(row, "description")
    if desc:
        if isinstance(desc, list):
            desc = " ".join(desc)
        fields.append(str(desc)[:desc_chars])
    return " | ".join(fields)
```

```python
# src/jevrec/data/collate.py
"""RankingSample → tensor batch.

Layout (spec §4.1): [context (l_ctx)][cand_1 (l_cand)] ... [cand_N (l_cand)]

Three non-negotiable details:
  1. position_ids reset per segment — otherwise candidate order leaks into the score (spec §4.2①)
  2. left padding on candidate segments — guarantees the scoring position is fixed at the end of the segment
  3. seg_id: 0 means context, i means the i-th candidate (starting from 1)
"""
from dataclasses import dataclass
import torch


@dataclass
class JevRecBatch:
    input_ids: torch.Tensor       # (B, L)
    position_ids: torch.Tensor    # (B, L)
    seg_id: torch.Tensor          # (B, L)  0=context, 1..N=candidates
    is_pad: torch.Tensor          # (B, L)  bool
    score_index: torch.Tensor     # (B, N)  absolute scoring position for each candidate
    labels: dict[str, torch.Tensor]  # target name -> (B, N)

    def to(self, device):
        return JevRecBatch(
            self.input_ids.to(device), self.position_ids.to(device),
            self.seg_id.to(device), self.is_pad.to(device),
            self.score_index.to(device),
            {k: v.to(device) for k, v in self.labels.items()},
        )


def _encode_fixed(text: str, tokenizer, length: int, pad_id: int, left: bool):
    """Encode text to a fixed length. Left-pads when left=True."""
    ids = tokenizer(text, add_special_tokens=False)["input_ids"][:length]
    n_pad = length - len(ids)
    pad = [pad_id] * n_pad
    if left:
        return pad + ids, [True] * n_pad + [False] * len(ids)
    return ids + pad, [False] * len(ids) + [True] * n_pad


def build_batch(samples, tokenizer, *, l_cand: int, n_ctx_items: int,
                l_ctx_per_item: int) -> JevRecBatch:
    pad_id = tokenizer.pad_token_id or tokenizer.eos_token_id
    l_ctx = n_ctx_items * l_ctx_per_item
    n_cand = samples[0].n_candidates
    ids_b, pos_b, seg_b, pad_b, sidx_b = [], [], [], [], []

    for s in samples:
        assert s.n_candidates == n_cand, "candidate count must be identical within a batch"
        ids, pads = [], []
        # --- context: take the most recent n_ctx_items entries, pad with empty strings if fewer ---
        hist = s.context_texts[-n_ctx_items:]
        hist = [""] * (n_ctx_items - len(hist)) + hist
        for t in hist:
            i, p = _encode_fixed(t, tokenizer, l_ctx_per_item, pad_id, left=False)
            ids += i; pads += p
        pos = list(range(l_ctx))
        seg = [0] * l_ctx
        sidx = []
        # --- candidates: left padding, position resets from l_ctx ---
        for j, t in enumerate(s.candidate_texts):
            i, p = _encode_fixed(t, tokenizer, l_cand, pad_id, left=True)
            ids += i; pads += p
            pos += list(range(l_ctx, l_ctx + l_cand))   # ← resets for every segment
            seg += [j + 1] * l_cand
            sidx.append(l_ctx + (j + 1) * l_cand - 1)   # ← end of the segment
        ids_b.append(ids); pos_b.append(pos); seg_b.append(seg)
        pad_b.append(pads); sidx_b.append(sidx)

    keys = samples[0].labels.keys()
    labels = {
        k: torch.tensor([s.labels[k] for s in samples], dtype=torch.float32)
        for k in keys
    }
    return JevRecBatch(
        input_ids=torch.tensor(ids_b, dtype=torch.long),
        position_ids=torch.tensor(pos_b, dtype=torch.long),
        seg_id=torch.tensor(seg_b, dtype=torch.long),
        is_pad=torch.tensor(pad_b, dtype=torch.bool),
        score_index=torch.tensor(sidx_b, dtype=torch.long),
        labels=labels,
    )
```

```python
# src/jevrec/model/mask.py
"""Block-diagonal + shared-prefix attention mask (spec §4.1).

Each candidate segment can see: the full context, and its own segment (causally);
it cannot see: any other candidate segment, or any pad token.

Uses a 4D additive mask with SDPA first — natively supported by transformers, easy
to verify for correctness. The FlexAttention version lives in scripts/bench_attn.py
(Task 8), purely as a performance optimization.
"""
import torch


def build_block_diagonal_mask(seg_id: torch.Tensor, is_pad: torch.Tensor,
                              dtype: torch.dtype = torch.bfloat16) -> torch.Tensor:
    """Returns a (B, 1, L, L) additive mask: 0 where visible, the dtype's minimum value where not."""
    B, L = seg_id.shape
    dev = seg_id.device

    q_seg = seg_id.unsqueeze(-1)              # (B, L, 1)  segment the query belongs to
    k_seg = seg_id.unsqueeze(-2)              # (B, 1, L)  segment the key belongs to
    visible = (k_seg == 0) | (q_seg == k_seg)  # sees context, or sees within its own segment

    idx = torch.arange(L, device=dev)
    causal = idx.unsqueeze(0) <= idx.unsqueeze(1)   # (L, L), [q, kv] = kv <= q

    not_pad = (~is_pad).unsqueeze(-2)          # (B, 1, L), applies to keys

    allow = visible & causal.unsqueeze(0) & not_pad   # (B, L, L)

    mask = torch.zeros(B, 1, L, L, dtype=dtype, device=dev)
    mask.masked_fill_(~allow.unsqueeze(1), torch.finfo(dtype).min)
    return mask
```

```python
# src/jevrec/model/heads.py
"""Output heads (spec §4.3).

Binary fields use a scalar sigmoid: under binary labels a K-bin distributional head
degenerates into a two-ended bimodal distribution, the middle bins are dead
parameters, and the entropy carries no information beyond the sigmoid (proven in
spec §4.3). watch-ratio is continuous and naturally bimodal, so it uses the K-bin
distributional head.
"""
import torch
import torch.nn as nn


class SigmoidHead(nn.Module):
    """(B, N, d) -> (B, N) logit."""

    def __init__(self, d: int, hidden: int | None = None):
        super().__init__()
        hidden = hidden or d
        self.net = nn.Sequential(nn.Linear(d, hidden), nn.GELU(), nn.Linear(hidden, 1))

    def forward(self, h: torch.Tensor) -> torch.Tensor:
        return self.net(h).squeeze(-1)


class BinnedHead(nn.Module):
    """A distributional head over K bins, for continuous, multimodal targets like watch-ratio."""

    def __init__(self, d: int, k: int = 64, v_max: float = 1.2,
                 hidden: int | None = None):
        super().__init__()
        hidden = hidden or d
        self.k, self.v_max = k, v_max
        self.net = nn.Sequential(nn.Linear(d, hidden), nn.GELU(), nn.Linear(hidden, k))
        self.register_buffer("bin_centers", torch.linspace(0.0, v_max, k))

    def forward(self, h: torch.Tensor) -> torch.Tensor:
        return self.net(h)                       # (B, N, K)

    def expectation(self, logits: torch.Tensor) -> torch.Tensor:
        p = torch.softmax(logits.float(), dim=-1)
        return (p * self.bin_centers.to(p.dtype)).sum(-1)

    def confidence(self, logits: torch.Tensor) -> torch.Tensor:
        """1 - normalized entropy. The more concentrated the distribution, the more confident."""
        p = torch.softmax(logits.float(), dim=-1)
        ent = -(p * (p + 1e-12).log()).sum(-1)
        import math
        return 1.0 - ent / math.log(self.k)
```

```python
# src/jevrec/model/backbone.py
"""Qwen3 backbone loading. Removes the LM head, and asserts at load time that there
are no sliding-window layers.
"""
import torch
from transformers import AutoConfig, AutoModel


class SlidingWindowError(RuntimeError):
    """Raised when the backbone contains SWA layers — this would break the
    block-diagonal mask's semantics (spec §4.2②)."""


def assert_no_sliding_window(cfg) -> None:
    layer_types = getattr(cfg, "layer_types", None)
    if layer_types is not None and any("sliding" in str(t) for t in layer_types):
        raise SlidingWindowError(f"backbone contains sliding-window layers: {layer_types}")
    if getattr(cfg, "use_sliding_window", False) and getattr(cfg, "sliding_window", None):
        raise SlidingWindowError(
            f"use_sliding_window=True, window={cfg.sliding_window}"
        )


def load_backbone(model_id: str, dtype: torch.dtype = torch.bfloat16):
    """Returns (backbone with the LM head removed, hidden_size)."""
    cfg = AutoConfig.from_pretrained(model_id)
    assert_no_sliding_window(cfg)
    model = AutoModel.from_pretrained(
        model_id, torch_dtype=dtype, attn_implementation="sdpa"
    )
    return model, cfg.hidden_size
```

```python
# src/jevrec/model/jevrec.py
"""JevRec: score N candidates in a single forward pass."""
import torch
import torch.nn as nn

from jevrec.data.collate import JevRecBatch
from jevrec.model.backbone import load_backbone
from jevrec.model.heads import SigmoidHead, BinnedHead
from jevrec.model.mask import build_block_diagonal_mask


class JevRec(nn.Module):
    def __init__(self, model_id: str, binary_targets: list[str],
                 binned_targets: list[str], k: int = 64,
                 v_max: float = 1.2, dtype: torch.dtype = torch.bfloat16):
        super().__init__()
        self.backbone, d = load_backbone(model_id, dtype=dtype)
        self.dtype = dtype
        self.binary_targets = list(binary_targets)
        self.binned_targets = list(binned_targets)
        self.heads = nn.ModuleDict(
            {t: SigmoidHead(d) for t in self.binary_targets}
            | {t: BinnedHead(d, k=k, v_max=v_max) for t in self.binned_targets}
        )
        self.heads.to(dtype)

    def forward(self, batch: JevRecBatch) -> dict[str, torch.Tensor]:
        dev = next(self.backbone.parameters()).device
        batch = batch.to(dev)
        mask = build_block_diagonal_mask(batch.seg_id, batch.is_pad, dtype=self.dtype)

        hidden = self.backbone(
            input_ids=batch.input_ids,
            position_ids=batch.position_ids,
            attention_mask=mask,
        ).last_hidden_state                       # (B, L, d)

        # extract the hidden state at the end of each candidate segment
        idx = batch.score_index.unsqueeze(-1).expand(-1, -1, hidden.size(-1))
        h = hidden.gather(1, idx)                 # (B, N, d)

        return {name: head(h) for name, head in self.heads.items()}
```

```python
# scripts/bench_attn.py
"""Compares throughput between two paths (spec §7.2):
  A. Block-diagonal mask, one forward pass scoring N candidates (SDPA 4D mask)
  B. Scoring candidates one at a time across N runs (naive baseline, used to
     quantify how much the block-diagonal mask actually saves)
Measures A's speedup over B, to decide whether it's worth adding FlexAttention.
"""
import argparse, time, torch, numpy as np
from transformers import AutoTokenizer
from jevrec.data.schema import RankingSample
from jevrec.data.collate import build_batch
from jevrec.model.jevrec import JevRec


def timed(fn, warmup=3, iters=10):
    for _ in range(warmup):
        fn()
    torch.cuda.synchronize(); t0 = time.perf_counter()
    for _ in range(iters):
        fn()
    torch.cuda.synchronize()
    return (time.perf_counter() - t0) / iters


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--model", default="Qwen/Qwen3-0.6B-Base")
    ap.add_argument("--n-cand", type=int, default=100)
    ap.add_argument("--n-ctx", type=int, default=20)
    ap.add_argument("--l-item", type=int, default=24)
    a = ap.parse_args()

    tok = AutoTokenizer.from_pretrained(a.model)
    model = JevRec(a.model, binary_targets=["click"], binned_targets=[]).cuda().eval()
    kw = dict(l_cand=a.l_item, n_ctx_items=a.n_ctx, l_ctx_per_item=a.l_item)

    ctx = [f"watched video number {i} about topic {i % 7}" for i in range(a.n_ctx)]
    cands = [f"a {20 + i % 40}s short video about topic {i % 11}" for i in range(a.n_cand)]

    # --- A: one forward pass scoring N candidates ---
    batch_all = build_batch(
        [RankingSample("u", ctx, cands, {"click": np.eye(a.n_cand)[0]})], tok, **kw)
    with torch.no_grad():
        t_block = timed(lambda: model(batch_all))

    # --- B: one forward pass per candidate ---
    singles = [
        build_batch([RankingSample("u", ctx, [c], {"click": np.array([1.0])})], tok, **kw)
        for c in cands
    ]
    with torch.no_grad():
        t_naive = timed(lambda: [model(b) for b in singles], warmup=1, iters=3)

    per_cand_block = t_block / a.n_cand * 1000
    per_cand_naive = t_naive / a.n_cand * 1000
    lines = [
        "| Path | End-to-end latency (ms) | Per candidate (ms) | Candidates scored per second |",
        "|---|---|---|---|",
        f"| A: block mask, single forward | {t_block*1000:.1f} | {per_cand_block:.3f} | {a.n_cand/t_block:.0f} |",
        f"| B: one forward per candidate, N passes | {t_naive*1000:.1f} | {per_cand_naive:.3f} | {a.n_cand/t_naive:.0f} |",
        "",
        f"**Speedup B/A = {t_naive/t_block:.1f}×** (N={a.n_cand}, ctx={a.n_ctx}×{a.l_item} tokens)",
    ]
    out = "\n".join(lines)
    print(out)
    with open("results/tables/w0_attn_bench.md", "w") as f:
        f.write(out + "\n")


if __name__ == "__main__":
    main()
```

```python
# src/jevrec/data/kuairand.py
"""KuaiRand → RankingSample (spec §3.3).

Three key points:
  1. Split by time, never randomly — a random split would leak the future into the past
  2. split="train" uses normal exposure traffic; split="calib" keeps only the
     unbiased is_random samples
  3. Negatives use popularity-based sampling, closer to the real exposure distribution
"""
import numpy as np
import pandas as pd

from jevrec.data.schema import RankingSample, validate_sample
from jevrec.data.text import kuairand_item_text

TARGETS = ("click", "like", "follow", "watch_ratio")


def time_split(log_df: pd.DataFrame, train_frac: float = 0.8):
    df = log_df.sort_values("time_ms", kind="mergesort")
    cut = int(len(df) * train_frac)
    return df.iloc[:cut].copy(), df.iloc[cut:].copy()


def _popularity_table(df: pd.DataFrame) -> tuple[np.ndarray, np.ndarray]:
    counts = df["video_id"].value_counts()
    ids = counts.index.to_numpy()
    p = counts.to_numpy().astype(np.float64)
    return ids, p / p.sum()


def build_kuairand_samples(log_df: pd.DataFrame, item_df: pd.DataFrame, *,
                           n_ctx: int, n_cand: int, split: str,
                           seed: int = 42) -> list[RankingSample]:
    rng = np.random.default_rng(seed)
    texts = {r.video_id: kuairand_item_text(r._asdict())
             for r in item_df.itertuples(index=False)}
    pop_ids, pop_p = _popularity_table(log_df)

    df = log_df.sort_values(["user_id", "time_ms"], kind="mergesort")
    if split == "calib":
        target_rows = df[df["is_random"] == 1]
    else:
        target_rows = df[df["is_random"] == 0]

    samples: list[RankingSample] = []
    for uid, grp in df.groupby("user_id", sort=False):
        hist_ids: list[int] = []
        pos_rows = set(target_rows.index)
        for idx, row in grp.iterrows():
            if idx in pos_rows and len(hist_ids) >= n_ctx and row["is_click"] == 1:
                negs = _sample_negatives(rng, pop_ids, pop_p, n_cand - 1,
                                         exclude={row["video_id"], *hist_ids})
                cand_ids = [row["video_id"], *negs]
                order = rng.permutation(n_cand)
                cand_ids = [cand_ids[i] for i in order]
                labels = _build_labels(row, cand_ids, order, n_cand)
                s = RankingSample(
                    user_id=str(uid),
                    context_texts=[texts.get(i, "") for i in hist_ids[-n_ctx:]],
                    candidate_texts=[texts.get(i, "") for i in cand_ids],
                    labels=labels,
                    is_random_exposure=bool(row["is_random"]),
                )
                validate_sample(s)
                samples.append(s)
            hist_ids.append(row["video_id"])
    return samples


def _sample_negatives(rng, pop_ids, pop_p, k, exclude):
    out, guard = [], 0
    while len(out) < k and guard < 100 * k:
        pick = rng.choice(pop_ids, size=k, p=pop_p)
        for v in pick:
            if v not in exclude and len(out) < k:
                out.append(int(v)); exclude.add(int(v))
        guard += k
    while len(out) < k:                      # fallback for the extreme case
        out.append(int(rng.choice(pop_ids)))
    return out


def _build_labels(row, cand_ids, order, n_cand) -> dict[str, np.ndarray]:
    """The positive gets the real labels at its new position in order; negatives are all 0."""
    pos_new = int(np.where(order == 0)[0][0])
    labels = {t: np.zeros(n_cand, dtype=np.float32) for t in TARGETS}
    labels["click"][pos_new] = float(row["is_click"])
    labels["like"][pos_new] = float(row["is_like"])
    labels["follow"][pos_new] = float(row["is_follow"])
    dur = max(float(row["duration_ms"]), 1.0)
    labels["watch_ratio"][pos_new] = float(row["play_time_ms"]) / dur
    return labels
```

```python
# src/jevrec/train/losses.py
"""Training objectives (spec §5).

Combined loss: L = L_rank(listwise) + λ · L_cal(pointwise BCE)
A single shared score, no dual head — a dual head would hide the ranking/calibration
tension rather than resolve it (spec §5.4).

The base-rate correction is applied at **inference/evaluation time**; training uses
raw BCE (spec §5.5 L1).
"""
import math
import torch
import torch.nn.functional as F


def listwise_ce(scores: torch.Tensor, labels: torch.Tensor) -> torch.Tensor:
    """(B,N) scores + (B,N) one-hot → softmax cross-entropy. Invariant to an overall shift."""
    return F.cross_entropy(scores.float(), labels.float().argmax(dim=-1))


def pointwise_bce(logits: torch.Tensor, labels: torch.Tensor) -> torch.Tensor:
    return F.binary_cross_entropy_with_logits(logits.float(), labels.float())


def hl_gauss_targets(y: torch.Tensor, bin_centers: torch.Tensor,
                     sigma: float = 0.03) -> torch.Tensor:
    """Smear continuous targets into a Gaussian soft label (Farebrother et al. 2024). (B,N) -> (B,N,K)."""
    c = bin_centers.to(y.device).view(1, 1, -1).float()
    d = (y.float().unsqueeze(-1) - c) / sigma
    w = torch.exp(-0.5 * d * d)
    return w / w.sum(-1, keepdim=True).clamp_min(1e-12)


def binned_ce(logits: torch.Tensor, soft_targets: torch.Tensor) -> torch.Tensor:
    logp = F.log_softmax(logits.float(), dim=-1)
    return -(soft_targets * logp).sum(-1).mean()


def apply_prior_correction(logits: torch.Tensor, pi_train: float,
                           pi_target: float) -> torch.Tensor:
    """Elkan 2001 base-rate correction. Training-set prior π_train → target prior π_target.

    Call this at **evaluation/inference** time; do not use it during training
    (otherwise it entangles with BCE's gradient).
    """
    shift = (math.log(pi_target / (1 - pi_target))
             - math.log(pi_train / (1 - pi_train)))
    return logits + shift


def combined_loss(out: dict, labels: dict, *, lam: float,
                  bin_centers: torch.Tensor | None = None,
                  sigma: float = 0.03,
                  rank_target: str = "click") -> dict:
    """Returns {"total", "rank", "cal", "binned"}, for logging each separately."""
    scores = out[rank_target]
    rank = listwise_ce(scores, labels[rank_target])
    cal = pointwise_bce(scores, labels[rank_target])
    binned = torch.zeros((), device=scores.device)
    for name, logits in out.items():
        if logits.dim() == 3:                       # distributional head
            assert bin_centers is not None, "distributional head requires bin_centers"
            binned = binned + binned_ce(
                logits, hl_gauss_targets(labels[name], bin_centers, sigma))
        elif name != rank_target:                   # other binary targets
            cal = cal + pointwise_bce(logits, labels[name])
    return {"total": rank + lam * cal + binned,
            "rank": rank.detach(), "cal": cal.detach(), "binned": binned.detach()}
```

```python
# src/jevrec/eval/ranking.py
"""Ranking metrics (spec §6.4). GAUC is the standard per-user AUC used in
recommendation systems."""
import numpy as np
from sklearn.metrics import roc_auc_score


def ndcg_at_k(scores: np.ndarray, labels: np.ndarray, k: int = 10) -> float:
    """scores/labels shaped (n_lists, n_cand). Binary relevance."""
    scores, labels = np.asarray(scores), np.asarray(labels)
    order = np.argsort(-scores, axis=1)[:, :k]
    gains = np.take_along_axis(labels, order, axis=1)
    discount = 1.0 / np.log2(np.arange(2, k + 2))
    dcg = (gains * discount).sum(axis=1)

    ideal = np.sort(labels, axis=1)[:, ::-1][:, :k]
    idcg = (ideal * discount).sum(axis=1)
    return float(np.mean(np.divide(dcg, idcg, out=np.zeros_like(dcg),
                                   where=idcg > 0)))


def gauc(scores: np.ndarray, labels: np.ndarray, user_ids: np.ndarray) -> float:
    """Per-user AUC weighted by exposure count. Users with only one class are
    skipped (AUC is undefined)."""
    scores, labels, user_ids = map(np.asarray, (scores, labels, user_ids))
    total_w, total = 0.0, 0.0
    for u in np.unique(user_ids):
        m = user_ids == u
        y = labels[m]
        if y.min() == y.max():
            continue
        w = m.sum()
        total += w * roc_auc_score(y, scores[m])
        total_w += w
    return float(total / total_w) if total_w else float("nan")


def bootstrap_ci(values: np.ndarray, n_boot: int = 1000, alpha: float = 0.05,
                 seed: int = 42) -> tuple[float, float]:
    """Bootstrap confidence interval over per-user/per-list metric values (spec §6.3)."""
    rng = np.random.default_rng(seed)
    v = np.asarray(values)
    means = v[rng.integers(0, len(v), size=(n_boot, len(v)))].mean(axis=1)
    return float(np.quantile(means, alpha / 2)), float(np.quantile(means, 1 - alpha / 2))
```

```python
# src/jevrec/eval/leakage.py
"""Label leakage self-check (spec §11.3).

Usage: when a metric shows an anomalously good number, rerun the same pipeline
with shuffled labels. If the metric is still significantly above chance level,
it means the model is copying answers from label-derived features, or the eval
set has been contaminated by the training set — in that case this round's
results are entirely invalid.
"""
from dataclasses import replace
import numpy as np

from jevrec.data.schema import RankingSample


def shuffle_labels(samples: list[RankingSample], seed: int = 42) -> list[RankingSample]:
    """Randomly permute label positions within each list. Does not mutate the input."""
    rng = np.random.default_rng(seed)
    out = []
    for s in samples:
        perm = rng.permutation(s.n_candidates)
        out.append(replace(s, labels={k: np.asarray(v)[perm].copy()
                                      for k, v in s.labels.items()}))
    return out


def assert_chance_level(value: float, chance: float, tol: float, name: str) -> None:
    """After shuffling labels, the metric must fall back to chance level, otherwise
    this is judged to be leakage."""
    if value > chance + tol:
        raise AssertionError(
            f"Leakage alert: with shuffled labels, {name} = {value:.4f}, significantly above the chance level "
            f"{chance:.4f} (tolerance {tol}). This round's results are void; check: "
            f"(1) whether the temporal split leaks across time, (2) whether label-derived quantities crept into the features, (3) whether the eval set is contaminated by the training set."
        )
```

```python
# src/jevrec/train/loop.py
"""Training loop. See Global Constraints for the checkpoint retention policy: store
only bf16 weights, never optimizer state."""
from dataclasses import dataclass
import torch

from jevrec.data.collate import build_batch
from jevrec.train.losses import combined_loss


@dataclass
class TrainConfig:
    lam: float = 1.0
    lr: float = 1e-5
    batch_size: int = 8
    l_cand: int = 24
    n_ctx_items: int = 20
    l_ctx_per_item: int = 24
    grad_clip: float = 1.0
    sigma: float = 0.03
    seed: int = 42


def train_epoch(model, samples, tokenizer, cfg: TrainConfig, optimizer=None) -> dict:
    torch.manual_seed(cfg.seed)
    optimizer = optimizer or torch.optim.AdamW(model.parameters(), lr=cfg.lr)
    model.train()
    bin_centers = next(
        (h.bin_centers for h in model.heads.values() if hasattr(h, "bin_centers")), None)

    totals, n = {"total": 0.0, "rank": 0.0, "cal": 0.0, "binned": 0.0}, 0
    for i in range(0, len(samples), cfg.batch_size):
        chunk = samples[i: i + cfg.batch_size]
        batch = build_batch(chunk, tokenizer, l_cand=cfg.l_cand,
                            n_ctx_items=cfg.n_ctx_items,
                            l_ctx_per_item=cfg.l_ctx_per_item)
        out = model(batch)
        dev = next(model.parameters()).device
        labels = {k: v.to(dev) for k, v in batch.labels.items()}
        loss = combined_loss(out, labels, lam=cfg.lam,
                             bin_centers=bin_centers, sigma=cfg.sigma)
        loss["total"].backward()
        torch.nn.utils.clip_grad_norm_(model.parameters(), cfg.grad_clip)
        optimizer.step(); optimizer.zero_grad(set_to_none=True)
        for k in totals:
            totals[k] += float(loss[k])
        n += 1
    return {k: v / max(n, 1) for k, v in totals.items()}


def save_weights_only(model, path: str) -> None:
    """Store only bf16 weights, never optimizer state (the disk only has 50G)."""
    sd = {k: v.to(torch.bfloat16) for k, v in model.state_dict().items()}
    torch.save(sd, path)
```
